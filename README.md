# VALER × Salla — Twilight Bundle

هذا المستودع يحتوي إعدادات حزمة VALER لـ Salla وقالب الفاتورة الإلكترونية المخصص للعرض والطباعة.

## الملفات الرئيسية

- `twilight-bundle.json` — إعدادات حزمة Twilight واسم المشروع ووصفه ورابط الدعم.
- `package.json` — إعدادات مشروع Node/Vite.
- `invoice/valer-invoice.html` — قالب فاتورة A4 متجاوب.
- `invoice/invoice-data.example.json` — مثال لبيانات الفاتورة.
- `invoice/README.md` — تعليمات ربط قالب الفاتورة ببيانات الطلب.

## إعدادات VALER

- الاسم العربي: مجموعة VALER
- الاسم الإنجليزي: VALER Collection
- الدعم: https://valer.sa/support
- المستودع: https://github.com/intteeam-gif/tw-mgmoaah-valer

## تشغيل المشروع

يتطلب Node.js وpnpm.

```bash
pnpm install
pnpm run dev
```

لبناء المشروع:

```bash
pnpm run build
```

## ملاحظة مهمة عن الفاتورة

قالب الفاتورة الموجود في مجلد `invoice` هو **قالب عرض وطباعة** وليس نظام فوترة ZATCA Phase 2 كاملًا. لا تستخدم أرقام VAT أو السجل التجاري التجريبية الموجودة في ملف المثال على فاتورة حقيقية.

بيانات الفاتورة الرسمية، التوقيع، التشفير، والربط أو التخليص لدى ZATCA يجب أن تتم من خلال نظام الفوترة/التكامل المعتمد المستخدم فعليًا في المتجر.

## التطوير الآمن

قبل رفع أي تغيير إلى متجر Salla، اختبر:

1. صحة ملفات JSON.
2. تحميل القالب بدون أخطاء JavaScript.
3. حساب الخصم والشحن والضريبة.
4. الطباعة A4.
5. تمرير بيانات طلب حقيقية من طبقة التكامل.
6. بيانات VAT والسجل التجاري الرسمية.
